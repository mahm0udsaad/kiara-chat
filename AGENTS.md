# Product UX conventions

## True confirmation

- Any confirmation flow that sends a message or commits similar user-facing content must show the exact final content before the action.
- That content must be editable in the confirmation interface so the user can adjust it when needed. A read-only preview or a confirmation checkbox by itself is not a true confirmation.
- If the system appends something that cannot be edited, such as a signed link, show it clearly as an automatic addition before confirmation.
